# 🌌 Navinbalaji M — Interactive 3D Developer Portfolio

A modern, high-aesthetic developer portfolio featuring **procedural Three.js 3D WebGL graphics**, dark-mode glassmorphism, dynamic typewriter role switching, 3D card tilt physics, and an **embedded ATS-grade Resume viewer** with native print-to-PDF support.

---

## 🌟 Highlights & Key Features

- **Procedural 3D WebGL Canvas (`Three.js`)**:
  - Ambient particle constellation system reacting dynamically to cursor position and scroll depth.
  - Floating 3D wireframe icosahedron with glowing core and orbital ring.
  - High performance: 60 FPS requestAnimationFrame with graceful fallback.
- **ATS-Grade Resume Integration**:
  - Positioned prominently with quick navigation access and Hero CTA.
  - Interactive fullscreen ATS resume modal viewer.
  - Native browser Print / Save to PDF stylesheet (`@media print`) formatted cleanly for A4 paper.
  - One-click "Copy Resume Summary" and "Copy Email" with custom animated toast feedback.
- **Interactive 3D Tilt Physics**:
  - Perspective-based hover tilt (`perspective(1000px) rotateX/rotateY`) on project cards, experience cards, and credential badges.
- **Categorized Technical Matrix**:
  - Interactive filter buttons (*All, Programming & Core CS, Frontend, Backend & DB, AI & Tools*).
- **Responsive & Mobile Ready**:
  - Glassmorphic navigation header with blur backdrop and mobile drawer menu.

---

## 🛠️ Tech Stack

- **Graphics & 3D**: Three.js (r128), WebGL, Canvas API
- **Frontend Architecture**: Semantic HTML5, CSS3 Custom Properties, Modern JavaScript (ES6+)
- **Typography & Icons**: Poppins, Inter, JetBrains Mono, Font Awesome 6
- **Styling**: Cyber-Dark Glassmorphism (`backdrop-filter: blur()`), Custom CSS Gradients
